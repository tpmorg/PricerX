# Pricernu Mobile

Expo React Native app for the local-first object scanning experience.

The first implementation target is a mocked scan flow:

1. Create a local scan record.
2. Run mock OCR.
3. Run mock recognition.
4. Normalize object identity.
5. Run mock pricing.
6. Render the result.

Real camera, SQLite, Convex, Clerk, and Brave integrations will be added behind existing interfaces.
