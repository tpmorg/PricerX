# Task 0009 - Brand System Foundation

## Goal
Give Pricernu a coherent product identity before introducing a larger styling framework.

## Scope
- Define a shared brand palette, typography scale, spacing, radii, and shadow system.
- Add lightweight reusable UI primitives for brand presentation and screen sections.
- Apply the new brand system to the app shell and core tab screens.

## Notes
- Keep this pass implementation-focused and local to the existing Expo app.
- Use semantic tokens so a future NativeWind migration can encode the same decisions.
- Prefer a wordmark/monogram treatment over a decorative logo asset for now.
